# Challenge 1 - The Beginning

Welcome to challenge 1! Taking the first step to writing safer Daml code is admirable! But will you make it?...

This challenge is very straightforward - you are the financial auditor of an asset, but you are malicious, so steal it in whatever way you can!

This is of course only for educational purposes and to teach you how to NOT write Daml code. 

---

You can find the Daml contract in `1-TheBeginning/main/daml/Iou_Asset.daml`. Where you will examine the code and see if there is a way for you, as the auditor, to steal the asset for yourself. 

To check whether you're able to pull it off, enter your solution in the `1-TheBeginning/test/daml/Iou_Asset_Test.daml` test file. Make sure you only touch the marked area:

```haskell
-- ENTER SOLUTION BELOW --
    
-- ENTER SOLUTION ABOVE --
```

DO NOT TOUCH ANYTHING ELSE! 

P.S - I left no comments on the contract to make it so you really just need to rely on your ability of hacking and debugging. Sure, you can use AI but you will not learn anything...

Good luck!
