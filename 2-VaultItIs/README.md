# Challenge 2 - Vault It Is!

Ahh the vault! We all know and love vaults. But can you see what's wrong in this one?

Your job in this challenge - you are Bob! A trusted depositor on behalf of Alice. But you kind of want all of the money to yourself... Steal it in any way you can. 

This is of course only for educational purposes and to teach you how to NOT write Daml code. 

---

You can find the Daml contract in `2-VaultItIs/main/daml/SimpleVault.daml`. Where you will examine the code and see if there is a way for you, as the vault's trusted depositor, to get that money. 

To check whether you're able to pull it off, enter your solution in the `2-VaultItIs/test/daml/SimpleVaultTest.daml` test file. Make sure you only touch the marked area:

```haskell
-- ENTER SOLUTION BELOW --
-> Enter HERE!
-- ENTER SOLUTION ABOVE --
```

DO NOT TOUCH ANYTHING ELSE! 

P.S - I left no comments on the contract to make it so you really just need to rely on your ability of hacking and debugging. Sure, you can use AI but you will not learn anything...

Good luck!
